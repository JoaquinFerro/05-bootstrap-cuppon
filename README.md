# Cuppon — Landing de Cupones con Bootstrap

Landing page para una plataforma ficticia de cupones y ofertas, desarrollada
como ejercicio del **Módulo de Bootstrap** de mi formación en Desarrollo Web
Front-End con Desafío Latam.

Este proyecto es la **sexta pieza de mi portafolio**, después de
`01-curriculum-futbolista` (HTML básico), `02-curriculum-vitae-jferro`
(Bootstrap 5), `03-pizzeria-ramos` (CSS), `04-flexbox-iguana` (Flexbox) y
`06-flexbox-chat` (CSS avanzado). Aquí practiqué **Bootstrap 5** aplicado a
un caso real de e-commerce.

---

## 🎯 Objetivo

Practicar el uso de **Bootstrap 5** en un proyecto real:

- Uso del **grid system** (row + col) para layouts responsive
- Componentes de Bootstrap: **navbar, cards, forms, buttons**
- **Cards con list-group** para mostrar precios
- **Formulario** de suscripción con estilos de Bootstrap
- Clases utilitarias: `m-3`, `p-4`, `text-center`, `shadow`, `rounded`
- Personalización de estilos con CSS propio

---

## 🛠️ Tecnologías usadas

- **HTML5** — estructura semántica
- **CSS3** — estilos personalizados
- **Bootstrap 5.3.3** — framework responsive
- **Google Fonts (Roboto)** — tipografía
- **Font Awesome** — iconografía

## 🎨 Secciones del sitio

1. **Navbar** — Verde con logo y menú de navegación
2. **Main** — Grid con 6 cards de cupones:
   - Imagen
   - Título del cupón
   - Nombre de la empresa
   - Ubicación (con icono)
   - Precio original tachado + precio rebajado
3. **Formulario de suscripción** — Franja verde con campos de nombre y correo
4. **Footer** — Logo y copyright

---

## 🧠 Aprendizajes

- **Bootstrap 5 grid system:**
  - Uso de `container`, `row`, `col-*`
  - Breakpoints responsive (`col-12 col-md-6 col-lg-4`)
  - Alineación con clases utilitarias

- **Componentes de Bootstrap:**
  - Navbar responsive con toggler
  - Cards con `card-body`, `card-title`, `card-text`
  - `list-group` para precios
  - Formularios con `form-control` y `form-label`
  - Botones con `btn btn-light`

- **Clases utilitarias:**
  - Espaciado: `m-3`, `p-4`, `py-3`, `pt-3`
  - Texto: `text-center`, `text-end`, `fs-5`
  - Visuales: `shadow`, `rounded`
  - Colores: `bg-success`, `text-white`

- **CSS personalizado:** complementar Bootstrap con estilos propios.
